# Schriften für die 3D-Druck-Beschriftung

Ausgewählt wurden kräftige Schnitte mit gleichmäßiger Strichstärke, die sich
auch bei kleinen Schrifthöhen sauber drucken lassen. Die Dateien sind auf den
Zeichenvorrat Latin-1 (inkl. Umlaute und ß) reduzierte typeface.json-Fonts aus
den three.js-Beispielen.

| Datei          | Schrift           | Lizenz                                    |
| -------------- | ----------------- | ----------------------------------------- |
| `sans.json`    | Droid Sans Bold   | Apache 2.0 (`LICENSE-Droid-Apache-2.0.txt`) |
| `serif.json`   | Droid Serif Bold  | Apache 2.0 (`LICENSE-Droid-Apache-2.0.txt`) |
| `optimer.json` | Optimer Bold (MgOpen) | MgOpen-Lizenz (`LICENSE-MgOpen.txt`)  |
